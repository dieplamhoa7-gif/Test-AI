# Inspiration Sites Reference

When stuck on direction or need visual references, study these sites. They represent the target aesthetic quality bar.

## Tier 1: North Star References (study these closely)

**Linear** — linear.app
- WHY: The gold standard for dark-mode SaaS. Minimal, information-dense, no wasted pixels.
- STUDY: Their color system (true blacks, blue accent), typography (custom Inter variant), card borders (1px subtle), sidebar navigation, keyboard shortcuts UI.
- STEAL: Surface layering technique, border-only cards, monochromatic palette with single accent.

**Vercel** — vercel.com
- WHY: Clean editorial + product hybrid. Great at making technical content feel premium.
- STUDY: Their hero sections (bold headlines, product screenshots below), pricing page, docs layout.
- STEAL: Geist font usage, section spacing rhythm, gradient borders on hover.

**Attio** — attio.com
- WHY: Modern CRM that doesn't look like Salesforce. Warm dark theme, data-dense but breathable.
- STUDY: Their table views, record detail pages, sidebar + main content split.
- STEAL: How they handle high-density data without feeling cluttered.

**Raycast** — raycast.com
- WHY: Developer tool aesthetic done right. Fast, sharp, keyboard-native feel.
- STUDY: Command palette, extension store, settings UI.
- STEAL: Their dark theme warmth, icon system, compact component sizing.

## Tier 2: Pattern References (study specific elements)

**Stripe** — stripe.com / dashboard.stripe.com
- STUDY: Docs layout, API reference design, dashboard data visualization.
- STEAL: Their gradient technique (subtle, within one hue family), payment form UX.

**Notion** — notion.so
- STUDY: Content editing UX, sidebar hierarchy, minimal chrome.
- AVOID: Their overuse of emoji and playful tone (not Neej's aesthetic).

**Figma** — figma.com
- STUDY: Toolbar design, canvas UI, collaboration features UI.
- STEAL: Their floating panel design, compact controls.

**Arc Browser** — arc.net
- STUDY: Marketing site (editorial, bold typography, scroll-driven storytelling).
- STEAL: Their use of large serif headlines with clean sans-serif body.

**Resend** — resend.com
- STUDY: Developer-focused marketing that still looks premium.
- STEAL: Their dark theme, code-block styling, minimal hero with product focus.

**Cal.com** — cal.com
- STUDY: Open-source SaaS interface, scheduling UI patterns.
- STEAL: Clean form design, time-picker UX, settings panel layout.

## Tier 3: Animation & Interaction References

**Liveblocks** — liveblocks.io
- Real-time collaboration UI patterns, multiplayer cursor animations.

**Clerk** — clerk.com
- Auth component design, sign-in/sign-up flow patterns.

**Planetscale** — planetscale.com (now Vitess-focused)
- Database UI, schema visualization, branching UI metaphor.

**Railway** — railway.app
- Deploy UI, real-time log streaming, resource monitoring dashboards.

## Design Galleries (for broader inspiration)

- **Godly.website** — curated best-of-web design
- **Mobbin** — real app UI patterns (mobile + web), free tier available
- **Screenlane** — real product UI screenshots organized by component type
- **Dribbble** — filter for "Web Design" + "Dark" themes only (ignore the fantasy work). API available at developer.dribbble.com for programmatic access
- **Awwwards** — award-winning sites (study winners, not nominees)
- **SaaS Landing Page Examples** — saaslandingpage.com

## Design-to-Code Tools

- **Figma MCP** — official MCP server at `https://mcp.figma.com/mcp`. Read design files, extract tokens, write back to canvas. Free during beta. Use when a Figma file exists for the project.
- **v0.dev** — Vercel's AI component generator. Best for rapid UI prototyping with React + Tailwind. Use for inspiration, then adapt to project design tokens.
- **shadcn Visual Builder** — `npx shadcn create` or ui.shadcn.com/create. Generate themed project scaffolding with custom colors, fonts, icons. Use as project starting point.

## Anti-Inspiration (study what NOT to do)

- Generic WordPress themes — template-energy, no personality
- Default Material UI apps — Google aesthetic everywhere, no differentiation
- Bootstrap-heavy sites — grid-locked, every component looks the same
- Wix/Squarespace templates — consumer-grade, not SaaS-grade
- Most Y Combinator company landing pages — often rushed, generic hero + feature grid

## How to Use This List

1. **Starting a new project?** Open 2-3 Tier 1 sites, study them for 2 minutes, internalize the feeling
2. **Stuck on a specific component?** Search Tier 2 sites for that exact pattern
3. **Animation question?** Check Tier 3 sites for interaction references
4. **Need broader ideas?** Browse one gallery for 5 minutes max, then commit to a direction

The goal is NOT to copy any of these sites. The goal is to absorb their level of craft and intentionality, then apply that standard to whatever you're building. Every project should feel uniquely itself while meeting this quality bar.
