### Useful FB content themes for model improvement
These are not indicator tricks; they are risk/modeling frameworks worth incorporating.

1. **Macro early-risk overlay**
   - FB post theme: don't just read macro as “good/bad points”; treat macro data as early risk signals.
   - Transmission channels to model: funding cost, FX/tỷ giá, cash flow, margin pressure, risk appetite, liquidity tightness.
   - Model idea: create `macro_risk_score` and use it to adjust confidence/position sizing/strategy suitability.

2. **IPO / IC risk memo framing**
   - FB post theme: a buy-side analyst pitching an IPO should be able to state top 3 risks in 1 minute, not only growth/fair value.
   - Model/report idea: for new listings/hot stocks, add mandatory `top_3_risks`: earnings risk, liquidity/exit risk, governance/control/dilution/execution risk.

3. **Governance / control / liquidity exit risk**
   - FB post about Vicostone-Phenikaa / reverse takeover style case: traditional valuation (gross margin, NPAT, PE/DCF) can be insufficient when control/governance/liquidity/fund-exit dynamics dominate.
   - Model idea: add `structural_risk_score` = governance risk + control risk + liquidity exit risk + ownership concentration + delisting/corporate-action risk.
   - Particularly important for small/mid caps, low free-float names, M&A/restructuring/delisting cases.

4. **Option-like payoff / embedded structure thinking**
   - FB post about Vinhomes gold-to-property product: analyze as a financial structure with option-like payoff, not just marketing/product wording.
   - Risks mentioned: market risk of gold/property, liquidity risk, basis risk, legal risk, communication risk.
   - Model idea: add `special_structure_type` for cases like CW/warrants, convertible bonds, embedded guarantees, commodity-linked structures, conversion-linked/option-like products.

5. **Anti-self-deception / statistical discipline**
   - FB theme: statistics don't “trick” AI/traders; misuse/cherry-picking of data, parameters, backtest periods, and narrative confirmation does.
   - Reinforces Hòa's existing rules: no cherry-picking, no arbitrary parameter tuning, respect OOS/P70/robustness, avoid lookahead/survivorship bias.
   - Suggested checklist: in-sample vs OOS, parameter stability, regime sensitivity, survivorship bias, lookahead bias, costs/slippage, neighboring parameter robustness, cross-symbol/sector robustness.
